# HH Job Agent

**HH Job Agent** — учебный Python-проект для анализа вакансий с hh.ru и адаптации резюме под требования работодателя.

Проект помогает оценить соответствие резюме вакансии, определить недостающие навыки и сформировать отдельную версию резюме с учётом релевантных требований.

> Проект находится в стадии разработки. Получение вакансий через API hh.ru пока не является частью гарантированно работающего сценария. На текущем этапе текст вакансии передаётся вручную через веб-интерфейс.

## Возможности

- Анализ текста вакансии.
- Извлечение технологий и инструментов.
- Разделение навыков на обязательные, желательные и дополнительные.
- Определение условий работы и льгот.
- Сравнение требований вакансии с базовым резюме.
- Расчёт процента совпадения навыков.
- Выявление отсутствующих навыков.
- Адаптация резюме под конкретную вакансию.
- Проверка адаптированного резюме на достоверность.
- Сохранение результатов обработки каждой вакансии.
- Скачивание адаптированного резюме в формате Markdown.

## Как работает проект

1. Пользователь вставляет текст вакансии в веб-интерфейс.
2. Приложение анализирует описание и извлекает требования.
3. Требования сравниваются с базовым резюме.
4. Рассчитывается процент совпадения навыков.
5. Формируется адаптированная версия резюме.
6. Выполняется проверка достоверности.
7. Результаты сохраняются в отдельную папку истории обработки.
8. Пользователь может скачать сформированное резюме.

## Установка

Клонируйте репозиторий:

```bash
git clone https://github.com/Izmudin1991/hh-job-agent.git
cd hh-job-agent
```

Создайте виртуальное окружение:

```bash
python -m venv .venv
```

Активируйте его в Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

Установите зависимости:

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## Настройка

Создайте файл `.env` в корне проекта.

Добавьте необходимые переменные окружения, используемые в `src/resume/openai_client.py` и других модулях.

Например:

```env
OPENAI_API_KEY=your_api_key
```

Не публикуйте настоящий API-ключ и не добавляйте `.env` в Git.

## Запуск

Запустите веб-приложение:

```bash
python -m uvicorn web.app:app
```

Откройте в браузере:

```text
http://127.0.0.1:8000
```

Для остановки сервера нажмите `Ctrl + C`.

## История обработки вакансий

Результаты каждой обработки сохраняются в отдельной папке:

```text
data/vacancy_history/
```

Архив содержит:

- `vacancy.txt` — исходный текст вакансии;
- `analysis.json` — результаты анализа;
- `comparison.json` — сравнение с базовым резюме;
- `validation.json` — результаты проверки;
- `tailored_resume.md` — адаптированное резюме.

## Ограничения текущей версии

- Текст вакансии вводится вручную.
- Автоматическое получение вакансий с hh.ru пока не входит в основной рабочий сценарий.
- Сопоставление технологий основано на реализованных правилах анализа.
- Процент совпадения является ориентировочной оценкой соответствия навыков, а не гарантией успешного трудоустройства.
- Перед отправкой работодателю необходимо проверить личные данные и содержание адаптированного резюме.
